# Сборка Донгла с экраном (ErgoDox Dongle Display)

Данное руководство содержит всю необходимую информацию для аппаратной сборки второго (домашнего) донгла с дисплеем на базе микроконтроллера nice!nano v2 (или совместимого nRF52840) и 1.69" IPS дисплея ST7789V (18-пиновый FPC шлейф).

## 🛠 Компоненты

1. **Микроконтроллер**: nice!nano v2 (или ProMicro/SuperMini nRF52840)
2. **Дисплей**: 1.69" IPS с 18-пиновым FPC-шлейфом (контроллер ST7789V, разрешение 240x280)
3. Провода, паяльник, флюс.

---

## ⚡ Схема подключения (Wiring Guide)

Модуль дисплея использует 18-пиновый FPC-шлейф. Для отображения статуса ZMK требуется подключить **только дисплей и питание** (всего 7–8 физических проводов к контроллеру). Сенсорный слой (тачскрин) на данном этапе подключать **не нужно**.

Конфигурация опирается на файл прошивки `zmk-config/boards/shields/ergodox/ergodox_dongle_display.overlay`.

### 1. Попиновая таблица подключения 18-пинового FPC шлейфа

| № Pin (FPC) | Маркировка на шлейфе | Подключение к nice!nano v2 | Статус | Примечание |
|:---:|:---:|:---:|:---:|:---|
| **1** | **GND** | **GND** | **Обязательно** | Земля (объединить перемычкой с 5, 6, 12, 18) |
| **2** | **LEDK** | **010 (P0.10)** или **GND** | **Обязательно** | Минус подсветки (P0.10 для управления яркостью, либо напрямую GND для 100% яркости) |
| **3** | **VDD 3.0V** | **VCC (3.3V)** | **Обязательно** | Основное питание дисплея |
| **4** | **VDDIO 1.8V** | **VCC (3.3V)** | **Обязательно** | Питание логики (объединить с пином 3 к шине 3.3V) |
| **5** | **GND** | **GND** | **Обязательно** | Земля |
| **6** | **GND** | **GND** | **Обязательно** | Земля |
| **7** | **D/C** | **104 (P1.04)** | **Обязательно** | Данные / Команда (Data/Command) |
| **8** | **CS** | **106 (P1.06)** | **Обязательно** | Выбор чипа (Chip Select SPI) |
| **9** | **SCL** | **113 (P1.13)** | **Обязательно** | Тактовый сигнал SPI (Clock / SCK) |
| **10** | **SDA** | **115 (P1.15)** | **Обязательно** | Линия данных SPI (MOSI / Data In) |
| **11** | **RESET** | **011 (P0.11)** | **Обязательно** | Аппаратный сброс (Reset) |
| **12** | **GND** | **GND** | **Обязательно** | Земля |
| **13** | **TP_SCL** | *Не подключать* (NC) | *Опционально* | Тачскрин: I2C Clock (резерв: пин `020`) |
| **14** | **TP_SDA** | *Не подключать* (NC) | *Опционально* | Тачскрин: I2C Data (резерв: пин `017`) |
| **15** | **TP_TRST** | *Не подключать* (NC) | *Опционально* | Тачскрин: Reset (резерв: пин `002`) |
| **16** | **TP_TINT** | *Не подключать* (NC) | *Опционально* | Тачскрин: Прерывание IRQ (резерв: пин `009`) |
| **17** | **VDD 3.0V** | *Не подключать* (NC) | *Опционально* | Питание контроллера тачскрина |
| **18** | **GND** | **GND** | **Обязательно** | Земля |

### 2. Практические советы по пайке:

1. **Линии GND (пины 1, 5, 6, 12, 18):**
   * Не нужно тянуть 5 отдельных проводов на микроконтроллер.
   * Замкните их между собой перемычками прямо на стороне разъема/платы дисплея и выведите **один общий провод** на контакт **GND** платы nice!nano.
2. **Линии питания (пины 3 и 4):**
   * Соедините пины **3 (VDD)** и **4 (VDDIO)** вместе и подключите одним проводом к выводу **VCC (3.3V)** nice!nano.
3. **Подсветка (пин 2 LEDK):**
   * Если хотите, чтобы экран автоматически гас при бездействии — подключите к **010 (P0.10)** (настроен PWM в прошивке).
   * Если хотите постоянную подсветку без регулировки — можно просто подключить к **GND**.
4. **Сенсорный экран (пины 13–17):**
   * Оставьте их свободными (не припаивайте к ним провода). Для виджета YADS в ZMK они не требуются.

## 💻 Прошивка (Software)

Так как изменения уже закоммичены и отправлены в ваш репозиторий `zmk-config`, GitHub Actions собирает:
- `ergodox_dongle.uf2` (для походного донгла без экрана)
- `ergodox_dongle_display.uf2` (для домашнего донгла с экраном)

### Как прошить:
1. Подключите собранный донгл к компьютеру по USB.
2. Дважды быстро нажмите кнопку **Reset** на nice!nano (или замкните пины RST и GND пинцетом два раза).
3. Появится флеш-накопитель `NICENANO`.
4. Скопируйте туда файл `ergodox_dongle_display.uf2`.
5. Контроллер автоматически перезагрузится, и на экране появится интерфейс ZMK Dongle Screen (YADS).

---

## ⚙️ Управление с клавиатуры

Прошивка настроена так, что экран выключается автоматически при простое клавиатуры. При нажатии на любую клавишу — он мгновенно просыпается.

Модуль [YADS (Yet Another Dongle Screen)](https://github.com/janpfischer/zmk-dongle-screen) по умолчанию выводит:
* Текущий активный слой (словами или номером).
* Активные модификаторы (Shift, Ctrl, Alt, GUI).
* Индикатор WPM (слов в минуту).
* Уровни заряда батареи обеих половинок (левой и правой).
* Состояние подключения (USB белый/красный, Bluetooth зеленый/синий/белый).
