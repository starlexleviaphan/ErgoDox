## ⚡ Быстрая сводка ключевых параметров

| Параметр Oryx/QMK | Значение в конфиге | Назначение |
| :--- | :--- | :--- |
| **Базовый тайминг (`TAPPING_TERM`)** | `190 ms` (дефолт QMK: 200) | Быстрый отклик tap-hold клавиш |
| **Индивидуальный Tapping Term** | `g_tapping_term - 40` (`150 ms`) | На клавишах `LGUI(G)` и `RGUI(K)` для исключения ложных Win/Cmd при роллах |
| **Chordal Hold** | `ON` (матрица L/R) | Исключает ложные модификаторы при быстрой печати одной рукой |
| **Permissive Hold** | `ON` | Срабатывание модификатора при быстром перекрытии клавиш |
| **Quick Tap Term** | `0 ms` | Отключает автоповтор буквы при быстром двойном тапе tap-hold клавиши |
| **AutoShift** | `ON` (только слой TYPE) | Тап = строчная, удержание >120ms = заглавная |
| **AutoShift Timeout** | `120 ms` | Минимальная задержка для быстрого набора прописных букв |
| **One-Shot Timeout** | `5000 ms` | Время ожидания следующего символа после нажатия One-Shot клавиши |
| **One-Shot Tap Toggle** | `2` | Двойной тап по One-Shot клавише фиксирует её (Caps/Mod Lock) |
| **Layer Lock** | `QK_LLCK` | Фиксация мгновенного вспомогательного слоя в постоянный |
