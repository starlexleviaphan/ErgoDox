## ⚙️ Сводный анализ нестандартных директив

В данной раскладке стандартное поведение QMK/Oryx существенно модифицировано для достижения высокой стабильности при слепой печати и предотвращения ложных срабатываний (misﬁres).

### Таблица флагов и параметров

| :--- | :--- | :--- | :--- |

## 1. Механика Chordal Hold (Двуручная фильтрация Home Row Mods)

Главная проблема Home Row Mods при быстрой печати — так называемые **«одноручные перекаты» (same-hand rolls)**.
Например, если вы печатаете слово `st` очень быстро:
1. Вы нажимаете `S` (на котором висит Shift).
2. Не отпуская `S`, нажимаете `T` (на котором висит Ctrl).
3. Отпускаете `S`, затем `T`.
Без фильтрации прошивка подумает, что вы зажали `Shift + T` (или `Ctrl + S`), и вместо текста отправит шорткат в систему.

### Решение в коде автора:
В `keymap.c` задана матрица принадлежности клавиш к рукам `chordal_hold_layout`:
```c
const char chordal_hold_layout[MATRIX_ROWS][MATRIX_COLS] PROGMEM = LAYOUT_ergodox(
  'L', 'L', 'L', 'L', 'L', 'L', 'L',    'R', 'R', 'R', 'R', 'R', 'R', 'R',
  ...
);
```
**Правило Chordal Hold:**
- Если модификатор на левой руке нажат одновременно с клавишей **на правой руке**, модификатор срабатывает мгновенно.
- Если модификатор нажат одновременно с клавишей **на той же самой руке**, прошивка считает это опечаткой/перекатом и регистрирует обе клавиши как **обычные буквы**, предотвращая случайный шорткат!
- *Исключение*: Большие пальцы исключены из жесткой привязки, чтобы шорткаты `Ctrl+Z`, `Ctrl+C` левой рукой на слоях навигации работали мгновенно.

## 2. Индивидуальный таймаут клавиш (`get_tapping_term`)

В коде `keymap.c` реализована функция `get_tapping_term`:
```c
uint16_t get_tapping_term(uint16_t keycode, keyrecord_t *record) {
    switch (keycode) {
        case MT(MOD_LGUI, KC_G):
            return g_tapping_term - 40; // 150 мс вместо 190 мс!
        case MT(MOD_RGUI, KC_K):
            return g_tapping_term - 40; // 150 мс вместо 190 мс!
        default:
            return g_tapping_term;      // 190 мс
    }
}
```
### Зачем это сделано?
Клавиша `GUI` (`Win` на Windows / `Cmd` на macOS) — самая «опасная» на клавиатуре. Её случайное срабатывание сворачивает окна, открывает меню Пуск или глобальный поиск.
Указательные пальцы — самые быстрые и подвижные. Укороченный таймаут (150 мс) требует более акцентированного удержания, полностью исключая случайное открытие меню Пуск при беглой печати.

## 3. Отключение автоповтора тапа (`QUICK_TAP_TERM 0`)

В стандартном QMK, если вы быстро дважды нажимаете клавишу с Tap-Hold, второй раз интерпретируется как автоповтор (например, зажали букву для серии `aaaaa`).
Однако для Home Row Mods это фатально:
- Если вы печатаете слово с двойной буквой (например, `press`, `letter`), вы быстро дважды нажимаете клавишу.
- При стандартном QMK прошивка может решить, что вы хотите зажать модификатор!
- При `QUICK_TAP_TERM 0` этот автоповтор полностью отключен: каждое нажатие оценивается строго индивидуально.

## 4. Кастомные переопределения клавиш (`process_record_user`)

В коде `keymap.c` переопределены 5 специальных клавиш:

### 1) Стрелки и страницы: `DUAL_FUNC_0` и `DUAL_FUNC_1`
- `DUAL_FUNC_0`:
  - Тап = `KC_UP` (Стрелка вверх)
  - Удержание = `KC_PAGE_UP` (Страница вверх)
- `DUAL_FUNC_1`:
  - Тап = `KC_DOWN` (Стрелка вниз)
  - Удержание = `KC_PGDN` (Страница вниз)

### 2) Переключатели режимов: `DUAL_FUNC_2` и `DUAL_FUNC_4`
- `DUAL_FUNC_2` (на базовом слое WORK):
  - Тап = переключение на **слой 3 (TYPE)** через `layer_move(3)`
  - Удержание = `KC_RIGHT_SHIFT`
- `DUAL_FUNC_4` (на слое TYPE):
  - Тап = возврат на **слой 0 (WORK)** через `layer_move(0)`
  - Удержание = `KC_RIGHT_SHIFT`

### 3) Математическое равенство: `DUAL_FUNC_3`
- На слое `LNPD`:
  - Тап = стандартный знак равенства `=` (`KC_EQUAL`)
  - Удержание = знак равенства цифровой клавиатуры (`KC_KP_EQUAL`)

## 5. Макрос инкрементного ввода AutoNumber

На слое `ARRW` (Key 60) автор реализовал генератор последовательностей (от 1 до 255):
- **Обычный тап (T)**: Печатает следующее число в последовательности (1, 2, 3...).
- **Длинное нажатие (P)**: Сброс счетчика на 1 без печати.
- **Shift + Тап (S+T)**: Смена направления (инкремент / декремент).
- **Shift + Длинное нажатие (S+P)**: Переключение режима «Числа» / «Буквы» (A, B, C...).
- **Ctrl + Тап (C+T)**: Повторная печать текущего числа без сдвига.
- **Shift + Ctrl + Тап (S+C+T)**: Шаг вперед без печати.
- **Shift + Ctrl + Длинное нажатие (S+C+P)**: Шаг на 10 позиций вперед без печати.
*Используется для быстрого заполнения списков, таблиц и разметки кода.*
